# Projeto Pi Pico W: Transmissão de Sinal de SOS
## Introdução
Este projeto tem como objetivo utilizar o microcontrolador Raspberry Pi Pico W para transmitir um sinal de SOS através de um LED. A ideia é criar um sistema simples e eficiente que pode ser utilizado em situações de emergência.

## Materiais Necessários
- Raspberry Pi Pico W

- LED (preferencialmente vermelho)

- Resistor

- Fios jumper

## Circuito
Monte o circuito conforme o diagrama abaixo:

Conecte o anodo do LED ao pino GPIO 11 do Raspberry Pi Pico W.

Conecte o catodo do LED ao resistor e, em seguida, ao GND do Raspberry Pi Pico W.

## Código
O código está disponível no arquivo SOS.c.

## Conclusão
Este projeto simples demonstra como podemos utilizar o Raspberry Pi Pico W para criar um sistema de sinalização de emergência. Com algumas adaptações, o projeto pode ser expandido para incluir outros tipos de sinais ou dispositivos de saída.
